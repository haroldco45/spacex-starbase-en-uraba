# 🚀 SpaceX Starbase Urabá
### La Puerta de Colombia al Universo

**Desarrollada por Vibras Positivas HM — Derechos de Autor Reservados**

---

## 🌍 Descripción

PWA instalable de presentación de propuesta para un puerto espacial SpaceX en el **Golfo de Urabá, Antioquia, Colombia** — la ubicación más estratégica del planeta para lanzar cohetes al espacio.

Diseñada como presentación oficial dirigida a **Elon Musk y SpaceX**, con datos geográficos reales, imágenes reales del Golfo de Urabá y de SpaceX, y argumentos técnicos sólidos.

---

## ✨ Características

- 🚀 **PWA Instalable** — Funciona offline, instalable en móvil y desktop
- ⏰ **Reloj Real Colombia** — Fecha y hora UTC-5 en tiempo real
- ⏳ **Countdown Hipotético** — Cuenta regresiva al primer lanzamiento soñado (4 Julio 2030)
- 🌌 **Starfield Animado** — Cielo estrellado generado con Canvas
- 📊 **Tabla Comparativa** — Urabá vs los mejores puertos espaciales del mundo
- 🗺️ **Mapa Real** — OpenStreetMap del Golfo de Urabá
- 📸 **Imágenes Reales** — NASA, SpaceX, Wikipedia
- 🎨 **Diseño Sci-Fi Épico** — Fuentes Orbitron + Rajdhani + Share Tech Mono
- 🗓️ **Roadmap 2026-2030** — Plan de desarrollo por fases
- 🇨🇴 **Colores Colombia** — Acento en amarillo, azul y rojo

## 🚀 Despliegue

### Opción 1: GitHub Pages
```bash
git init
git add .
git commit -m "🚀 SpaceX Starbase Urabá PWA"
git branch -M main
git remote add origin https://github.com/haroldco45/spacex-uraba.git
git push -u origin main
# Activar GitHub Pages en Settings > Pages
```

### Opción 2: Netlify
Arrastrar la carpeta a [netlify.com/drop](https://app.netlify.com/drop)

### Opción 3: Local
```bash
# Necesitas servidor HTTP (no abrir directo por CORS)
npx serve .
# o
python -m http.server 8080
```
